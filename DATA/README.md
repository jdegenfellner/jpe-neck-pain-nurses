# Data

The individual-level data set (`schwyz_data_Doris2026.csv`, one row per
participant, semicolon-separated) is **not** distributed with this repository.
It contains age, sex, profession, BMI, pain scores and joint position error
measurements of 42 hospital nurses and cannot be shared publicly.
Requests for data access should be directed to the corresponding author
(see the main README).

To run the scripts, place the file in this folder.
